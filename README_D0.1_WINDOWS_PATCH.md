# D0.1 Windows patch

Extract to a new folder. Run `Run_Tests.bat` and `Launch_Green_Light.bat`. Both configure bundled timezone data automatically. Python 3.10+ with Tkinter is required; no pip installation required. Existing operational SQLite records remain in the Windows per-user data directory outside the ZIP. See `CHANGE_REPORT_D0.1_WINDOWS_PATCH.md`.
