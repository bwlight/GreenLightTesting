# Green Light D0.1 — Windows test package

Double-click `Launch_Green_Light.bat`. Python 3.10+ with Tkinter is required; no pip packages are required. Open the default **5 Operational visits** tab. Search, select, correct with reason, and inspect audit history there. See `CHANGE_REPORT_D0.1.md` for testing instructions.

**Important:** Tab 5 writes operational data under your Windows user profile, not in the ZIP folder. Tabs 1–4 are synthetic/engineering only. Backups and restore are **not** implemented yet. D0.2 and D0.3 remain mandatory release gates.
